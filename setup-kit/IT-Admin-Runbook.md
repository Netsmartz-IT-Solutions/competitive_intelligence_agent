# IT Admin Runbook

## Deployment Checklist
- Confirm Microsoft 365 Copilot and Teams access for the intended users.
- Verify the declarative agent manifest and icons are packaged correctly.
- Validate that policy and data access permissions are aligned with the approved content sources.
- Review tenant isolation and ensure no cross-tenant data is exposed.

## Operational Guidance
- Monitor usage for questions outside the approved scope.
- Review source document access on a regular cadence.
- Keep competitor data repositories current and tagged for searchability.
